### 🎯 Overview

**Alliance Insurance Assistant** is a production-grade AI chatbot designed to revolutionize customer support in the insurance sector. By leveraging **Retrieval-Augmented Generation (RAG)** and **Sentiment Analysis**, the system provides accurate policy information while automatically escalating grievances when negative sentiment is detected.

- 🚀 **Core Feature**: Context-aware answering using enterprise insurance documents.
- 🛠️ **Sentiment Intelligence**: Automatically detects user frustration and registers formal complaints.
- 🔍 **Scalable Architecture**: Decoupled FastAPI backend with a lightweight, responsive frontend.

---

### 🛡️ Core Competencies

| Component | Technology | Role |
| :--- | :--- | :--- |
| **Backend** | FastAPI (Python) | High-performance API orchestration |
| **AI/ML Engine** | RAG (LangChain/Llama) | Contextual information retrieval |
| **Sentiment Analysis** | NLP Pipeline | Real-time emotional intelligence & escalation |
| **Frontend** | Vanilla JS / CSS3 | Modern, responsive glassmorphism UI |
| **Database** | Vector DB / SQLite | Knowledge storage & complaint management |

---

### 🌟 Key Features

- **RAG-Powered Conversations**: Retrieves precise answers from insurance policy documents, ensuring high factual accuracy.
- **Automated Escalation**: If the system detects anger or dissatisfaction, it instantly generates a unique Complaint ID and logs it for human review.
- **Seamless UI**: A sleek, user-friendly interface with real-time typing indicators and intuitive design.
- **RESTful API**: Robust backend endpoints for chat, sentiment tracking, and complaint history.

### 🔧 Getting Started

#### Backend Setup
1. Navigate to the `backend` directory.
2. Create a virtual environment: `python -m venv .venv`
3. Install dependencies (if requirements.txt exists) or install FastAPI: `pip install fastapi uvicorn pydantic`
4. Run the server: `uvicorn main:app --reload`

#### Frontend Setup
1. Navigate to the `frontend` directory.
2. Open `index.html` in your browser or serve it using a local server.
